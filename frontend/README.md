# image-to-text — frontend

Next.js (App Router) + TypeScript + Tailwind + shadcn/ui. Visão geral do produto no [README](../README.md) da raiz; telas em [docs/layout/rotas-e-paginas.md](../docs/layout/rotas-e-paginas.md).

- `npm run dev` — servidor local em http://localhost:3000
- `npm test` — testes unitários (Vitest)
- `npm run test:e2e` — testes ponta a ponta (Playwright)
- `npm run lint` · `npx tsc --noEmit`
